Hand Chord Detector

Hand Chord Detector is a computer vision project that uses a webcam to recognize guitar chord hand positions and play the corresponding guitar sound in real time. The system processes live video input, detects hand landmarks, identifies chord shapes, and provides immediate audio feedback.


Technologies
Python
OpenCV
MediaPipe
NumPy
Motivation

This project explores how computer vision can be used to connect physical gestures with interactive audio feedback. By recognizing guitar chord shapes through a webcam, GuitarVision demonstrates a practical application of image processing and real-time gesture recognition.

Future goals: 
Training a TensorFlow model to recognize all kinds of hand positions in order to predict hand chords.
